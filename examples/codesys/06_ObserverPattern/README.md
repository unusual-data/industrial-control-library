# Project 06: Observer Pattern (Event Notification)

## 1. Objective
This project demonstrates the **Observer Pattern** (Publish-Subscribe) in IEC 61131-3.
The goal is to decouple the machine logic from the auxiliary systems (Signal Tower, Logger, HMI). The machine (Subject) simply notifies its subscribers about state changes without knowing who they are or what they do.

## 2. Technical Implementation
* **Interface (`I_Observer`):** A contract that defines the `.Update(eState)` method.
* **Subject (`FB_Machine`):** Manages a list of observers. When its state changes (`.SetState`), it iterates through the list and calls `.Update()` for each subscriber.
* **Concrete Observers:**
    * `FB_SignalTower`: Updates physical lights (Green/Red/Yellow) based on the state.
    * `FB_MaintenanceLogger`: Generates a text log only when an error occurs.
* **Zero Coupling:** The machine block has no input/output variables for lights or logs. It communicates strictly via the Interface.

## 3. How to Test in Simulation
Follow these steps to verify the event-driven architecture in CODESYS:

### Step 1: Initialize System
1.  Login and run the project.
2.  The `bInit` logic runs once to `Attach` the Signal Tower and Logger to the Machine.

### Step 2: Test "Running" State
1.  Set `bStartMachine` to **TRUE**.
2.  Observe `fbTower`. The `bGreenLight` becomes **TRUE** automatically.
3.  Observe `fbLogger`. `bAlarmActive` is **FALSE**.

### Step 3: Test "Error" State
1.  Set `bSimulateError` to **TRUE**.
2.  Observe `fbTower`. The `bGreenLight` turns off, and `bRedLight` becomes **TRUE**.
3.  Observe `fbLogger`. `bAlarmActive` becomes **TRUE** and `sLastLog` shows the critical fault message.

### Step 4: Test "Idle" State
1.  Set `bStopMachine` to **TRUE**.
2.  Observe `fbTower`. The `bYellowLight` becomes **TRUE**.
3.  Notice that `fbFillingMachine` updated both observers instantly without explicit code in the main program loop.

## 4. Key Variables to Monitor
| Variable | Location | Description |
| :--- | :--- | :--- |
| `_aObservers` | FB_Machine | Array holding the subscribed interfaces. |
| `_eState` | FB_Machine | Current state of the machine. |
| `bGreenLight` | FB_SignalTower | Output controlled by the observer logic. |
| `sLastLog` | FB_MaintenanceLogger | Message generated by the observer logic. |
